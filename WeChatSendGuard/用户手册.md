# 微信防错发提醒助手 · 用户手册

> 面向最终使用者。开发者/构建说明见 [README.md](./README.md)；`ocr` 段的手工微调见程序目录下的 `高级配置说明.md`。

---

## 1. 安装与启动

本程序为**绿色免安装**：无安装包、不写注册表、不装服务。

**前置条件**：需先安装 **.NET 10 桌面运行时**（Desktop Runtime x64，微软官网免费下载）。若双击后无反应，多半就是缺它（可从 Windows"事件查看器"或 .NET 官网确认）。

1. 新建一个目录（例如 `D:\Tools\WeChatSendGuard`），把**整个发布目录的内容**（`WeChatSendGuard.exe` 及同目录的 `models\`、`resource\` 与 Paddle/OpenCV 原生 `.dll`）一起放进去。**只拷 exe 无法运行** —— OCR 模型与原生库是旁挂文件。
2. 双击运行。首次启动会在**同目录**自动生成：
   - `config.json` —— 你的配置（名单、样式等）
   - `logs\` —— 运行日志（排障用）
3. 启动后：托盘出现图标，并弹出「状态」窗口。

**卸载**：托盘右键「退出」，然后删除整个目录即可（配置与日志都在目录内，一并删除）。

## 2. 界面速览

### 2.1 状态窗口

| 字段 | 含义 |
|------|------|
| 微信窗口 | 微信当前状态：微信前台 / 微信非前台 / 微信已最小化 / 未找到微信窗口 |
| 渲染区 | 微信会话内容区的物理像素矩形（提醒框就贴在这上面） |
| DPI | 微信窗口所在显示器的缩放率（真实 DPI，100% = 96） |
| 识别文本 | OCR 识别到的会话名；`—` 表示尚未识别到 |
| 风险判定 | 命中：xxx / 未命中 / 无法判定 |
| 覆盖层状态 | 未启用 / 未找到微信窗口 / 微信已最小化 / 微信非前台 / 无法识别当前会话 / 已识别，未命中名单 / 命中风险名单 |
| 识别耗时 | 单次 OCR 耗时（正常约 600 ms，越大越可能是 CPU 被占满） |

按钮：**设置…**、**重载配置**、**打开配置目录**、**退出**。

> 关闭状态窗口 = 收进托盘继续运行；要真正结束程序请用「退出」或托盘菜单「退出」。

### 2.2 托盘菜单（右键托盘图标）

- 显示状态窗口
- 启用提醒（勾选 = 开；**仅本次运行有效**，不改配置文件）
- 设置…
- 重载配置（手工改过 `config.json` 后用它生效）
- 打开配置目录
- 退出

## 3. 第一次配置

1. 点状态窗口的「**设置…**」（或托盘 → 设置…）。
2. 在「**风险名单**」区点「**添加**」，在「会话名」里填会话名 —— **与微信标题栏显示的文字完全一致**（如 `XX项目讨论群`）。
3. 「匹配模式」建议先用 **包含（推荐）**，即会话名**含有**你填的文字就算命中。
4. 点「**保存并应用**」。
5. 打开微信、切到该会话（保持微信在前台），应立刻看到红框。

**验证技巧**：切到该会话时，看状态窗口「识别文本」是否等于微信标题栏文字。若不等，说明识别没抓准，先按第 6 节排查，不要急着加名单。

## 4. 配置项详解

> 设置界面与 `config.json` 一一对应；改 `config.json` 后需「重载配置」生效。

### 4.1 运行

| 设置界面 | `config.json` | 默认 | 说明 |
|----------|---------------|------|------|
| 启用提醒（总开关） | `enabled` | `true` | 关掉 = 停止识别并隐藏一切提醒 |
| 窗口轮询(ms) | `windowPollMs` | `100` | 跟踪微信位置/大小的间隔，50~5000；越大越省电但跟随越钝 |
| 识别间隔(ms) | `ocrIntervalMs` | `800` | OCR 间隔，500~5000；**仅在微信前台时执行**。单次识别约 600 ms，设太小无意义 |
| 去抖次数 | `debounceCount` | `2` | 连续 N 次识别一致才切换状态；越大越稳、但切换后仍显示旧结果的时间越长 |

### 4.2 风险名单 / 匹配

| 设置界面 | `config.json` | 说明 |
|----------|---------------|------|
| 会话名 | `riskChats[].name` | 要提醒的会话名 |
| 匹配模式 | `riskChats[].mode` | `default`(继承) / `exact`(完全相等) / `contains`(包含) / `regex`(正则) |
| 备注 | `riskChats[].note` | 仅用于日志可读，不参与匹配 |
| 默认匹配模式 | `matching.defaultMode` | 名单项选"继承默认模式"时生效，默认 `contains` |
| 区分大小写 | `matching.caseSensitive` | 默认 `false`（不区分） |

### 4.3 提醒方式 · 红框

| 设置界面 | `config.json` | 默认 | 说明 |
|----------|---------------|------|------|
| 启用红框 | `border.enabled` | `true` | |
| 颜色 | `border.color` | `#E53935` | `#RRGGBB` 或 `#AARRGGBB` |
| 粗细 | `border.thickness` | `4` | 1~40（DIP） |
| 显示文字标签 | `border.showLabel` | `false` | |
| 标签格式 | `border.labelFormat` | `⚠ 风险聊天：{0}` | `{0}` 为命中的名单项 |

### 4.4 提醒方式 · GIF 悬浮窗

| 设置界面 | `config.json` | 默认 | 说明 |
|----------|---------------|------|------|
| 启用 GIF | `gif.enabled` | `true` | |
| GIF 文件 | `gif.file` | `resource\cat-run.gif` | 相对路径按**程序目录**解析；留空则用**内置循环动画** |
| 最大尺寸 | `gif.maxSize` | `128` | 16~512（96 DPI 基准，按 `dpi/96` 缩放） |
| 偏移 X / Y | `gif.offsetX` / `offsetY` | `750` / `450` | 相对微信渲染区左上角（96 DPI 基准） |

## 5. 匹配模式怎么选

| 模式 | 适用 | 例子 |
|------|------|------|
| **包含**（推荐） | 会话名较长、只记得关键词 | 名单填 `项目讨论` → 命中 `XX项目讨论群`、`项目讨论(3)` |
| **完全相等** | 只要精确命中、避免误伤 | 名单填 `家庭群` → 只命中标题恰为 `家庭群` 的会话 |
| **正则表达式** | 复杂规则（如多个候选） | `^(老板|Boss)$` |

> **名字短容易误伤**：例如名单只填"群"，几乎所有群都会命中。建议用"包含"时填足够长的片段。

## 6. 排障

| 现象 | 可能原因与处理 |
|------|----------------|
| 「识别文本」一直为 `—` | 微信不在前台 / 被最小化；或标题被其它窗口遮挡；或程序目录缺少 `models\paddle-ppocrv5-mobile\`（OCR 模型是旁挂文件，见第 1 节，**不要只拷贝 exe**） |
| 「微信窗口」显示"未找到微信窗口" | 微信没开 / 已退出；或微信版本窗口类名变化（日志会记录） |
| 识别文本有字但**不对**（缺字、错字） | 走 `高级配置说明.md` 的微调流程（调 `baseRegion` 与 `baseScale`） |
| 会话名**太长被省略号截断** | 微信标题被截断后**无法识别**（会漏报）。处理：用"包含"模式填前几个字，或把微信窗口拉宽使标题完整显示 |
| 命中名单却**不显示**提醒 | ① 微信是否在前台？② 红框/GIF 是否被关掉？③ 状态窗口「覆盖层状态」显示什么，按提示定位 |
| 红框位置**偏移** | 确认「DPI」显示与系统缩放一致；跨屏混合 DPI（两台显示器缩放不同）本版未实测，可先在同缩放显示器上使用 |
| 切会话后提醒**慢半拍** | 单次识别约 600 ms、去抖（`debounceCount`，默认 2）→ 最长约 1.6 s 才出现。可调小去抖或缩短识别间隔（更耗电），但受单次 OCR 耗时下限约束 |
| 改了配置**没生效** | 直接改 `config.json` 需点托盘「重载配置」；用设置界面则「保存并应用」即可 |

**日志**：程序目录 `logs\` 下的日志记录了配置加载、窗口出现/消失、最小化/恢复、识别参数与失败原因，是排障首选。

## 7. 重要提示（请务必知悉）

1. 本工具的识别是**弱信号**：微信改版、系统缩放变化、深色主题等都可能降低识别率。
2. **识别失败时不会给出"安全"提示** —— 没看到红框，既可能是"不是风险会话"，也可能是"没识别出来"。**不要把"没红框"当成安全保证。**
3. 超长会话名被截断时**会漏报**（见第 6 节）。
4. 本程序**不会**拦截发送、不读取聊天内容、不联网。
