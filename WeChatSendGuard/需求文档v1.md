# 微信防错发提醒助手（WeChat Send Guard）  
## 需求与开发计划文档

**版本**：v1.0  
**日期**：2026-09-27  
**技术路线**：方案二 —— 独立透明覆盖层窗口（不注入微信进程）

---

## 1. 项目背景与目标

### 1.1 背景
PC端微信中，群聊与私聊的聊天窗口视觉结构高度相似。用户打字时视线聚焦在底部输入框附近，最多扫到相邻几条消息，难以注意到顶部群名称。手快时容易把私密内容误发到群聊，造成尴尬甚至严重后果。

### 1.2 目标
开发一个轻量级Windows辅助工具，在微信聊天窗口上方叠加一个**独立、透明、不干扰操作**的提醒层。当检测到当前聊天窗口为**高风险群聊**时，通过醒目的视觉元素（如红色边框、标签、文字）进行强提醒，降低误发概率。

### 1.3 范围
- **包含**：窗口跟踪、聊天对象识别（MVP采用手动名单）、透明覆盖层绘制、配置界面、开关控制。
- **不包含**：修改微信客户端、拦截消息发送、读取聊天内容、自动判断所有群聊（后续迭代探索）。

---

## 2. 需求概述

### 2.1 用户故事
> 作为一个经常在PC微信上聊天的用户，我希望在打开一个群聊窗口时，能立刻看到明显的“群聊”标识，这样我就不会把私聊内容错发到群里。

### 2.2 核心需求
1. **实时跟随**：覆盖层始终贴合微信聊天窗口的位置和大小。
2. **群聊识别**：判断当前聊天窗口是否为群聊（MVP：基于用户配置的群名列表）。
3. **强视觉提醒**：在群聊窗口中显示醒目的边框、标签或文字。
4. **零干扰**：覆盖层不遮挡输入、不抢焦点、可鼠标穿透。
5. **可配置**：用户可管理群名列表、调整提醒样式、一键开关。

### 3.1 详细说明

#### FR-05 聊天对象识别（MVP方案）
- 通过 `GetWindowText` 或 UI Automation 获取当前激活的微信聊天窗口标题。
- 标题通常为聊天对象名称（好友昵称或群名称）。
- 用户预先在配置文件中维护“高危群聊名单”，支持精确匹配和模糊匹配（如包含关键字）。
- **后续迭代**：探索通过 UI Automation 读取聊天窗口右侧“聊天信息”按钮的辅助信息，或通过窗口控件树判断是否存在群成员列表，实现自动识别。

#### FR-06 强提醒样式
- **边框**：在聊天窗口四周绘制 4px 红色/橙色边框。
- **标签**：在窗口顶部或输入框上方悬浮显示“⚠️ 群聊：XXX”文字。
- **闪烁**：可选，首次进入群聊时边框闪烁 2 次。
- **透明度**：整体透明度可调，默认 0.85，确保醒目但不完全遮挡。

### 5.2 模块划分

| 模块 | 职责 | 关键技术 |
|------|------|----------|
| 窗口发现 | 定位微信主窗口和当前聊天窗口 | `EnumWindows`、`FindWindowEx`、类名 `WeChatMainWndForPC` |
| 位置跟踪 | 实时获取聊天窗口坐标 | `GetWindowRect`、`SetWinEventHook` 监听 `EVENT_OBJECT_LOCATIONCHANGE` |
| 识别匹配 | 获取窗口标题并与群名列表比对 | `GetWindowText`、UI Automation、正则匹配 |
| 覆盖层窗口 | 创建透明、穿透、置顶窗口并绘制 | WPF `AllowsTransparency`、`WS_EX_LAYERED`、`WS_EX_TRANSPARENT` |
| 配置管理 | 读写 JSON 配置，管理群名列表 | `System.Text.Json` |
| 托盘控制 | 系统托盘图标、右键菜单、热键 | `NotifyIcon`、`RegisterHotKey` |

### 5.3 关键技术点

#### 5.3.1 透明覆盖层窗口（WPF）
```csharp
// 窗口样式
WindowStyle = WindowStyle.None;
AllowsTransparency = true;
Background = Brushes.Transparent;
Topmost = true;
ShowInTaskbar = false;

// Win32 扩展样式
var hwnd = new WindowInteropHelper(this).Handle;
int exStyle = GetWindowLong(hwnd, GWL_EXSTYLE);
SetWindowLong(hwnd, GWL_EXSTYLE, exStyle | WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE);
```

#### 5.3.2 窗口跟踪
- 使用 `SetWinEventHook` 监听微信窗口的 `EVENT_OBJECT_LOCATIONCHANGE` 和 `EVENT_OBJECT_NAMECHANGE`。
- 备用方案：100ms 定时器轮询 `GetWindowRect`。
- 当微信窗口最小化或关闭时，隐藏覆盖层。

#### 5.3.3 聊天对象识别（MVP）
```csharp
// 获取当前激活的微信聊天窗口标题
IntPtr chatWnd = GetForegroundWindow();
StringBuilder title = new StringBuilder(256);
GetWindowText(chatWnd, title, 256);
string chatName = title.ToString();

// 与配置的群名列表比对
bool isGroup = groupList.Any(g => chatName.Contains(g, StringComparison.OrdinalIgnoreCase));
```

#### 5.3.4 绘制提醒
- 在覆盖层 WPF 窗口中放置 `Border` 和 `TextBlock`。
- 根据配置动态调整颜色、透明度、文字内容。
- 使用 `DispatcherTimer` 或 `CompositionTarget.Rendering` 更新位置。

### 5.4 技术栈建议
- **语言**：C# (.NET 8)
- **UI框架**：WPF
- **Win32 API**：P/Invoke `user32.dll`、`gdi32.dll`
- **UI Automation**：`UIAutomationClient`、`UIAutomationTypes`
- **配置**：JSON
- **打包**：单文件发布，或 Inno Setup 安装包

## 9. 验收标准

1. 覆盖层能准确跟随微信聊天窗口，位置误差 < 2px，延迟 < 100ms。
2. 当聊天窗口标题匹配配置的群名列表时，显示红色边框和“群聊”标签。
3. 覆盖层完全鼠标穿透，不影响微信正常输入和点击。
4. 支持至少 20 个群名的配置，配置保存后立即生效。
5. 连续运行 8 小时无崩溃，CPU 占用 < 1%，内存 < 50MB。
6. 提供托盘图标和全局热键（默认 `Ctrl+Alt+G`）控制开关。
7. 不注入微信进程，不读取聊天内容，不联网。

## 10. 后续扩展

- **自动群聊识别**：通过 UI Automation 读取聊天窗口右侧“聊天信息”按钮的 `AutomationId` 或控件树，判断是否为群聊。
- **敏感词提醒**：在群聊窗口中输入特定关键词时，覆盖层闪烁提醒。
- **发送前二次确认**：结合键盘钩子，在按下回车时弹出确认框（需谨慎，避免影响正常使用）。
- **多语言支持**：界面和提醒文字支持中英文。
